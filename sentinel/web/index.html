Enrôler un appareil

Un jeton unique est généré par terminal et conservé seulement sous forme de hachage côté serveur.

01 — Créer les identifiants

Important : copiez ce jeton maintenant. Il ne pourra plus être affiché.

02 — Installer le collecteur

Sur Windows, Linux ou macOS, copiez le projet et installez Python 3.10+ puis :

python -m pip install -r requirements.txt
python -m agent.collector --once
python -m agent.collector --interval 60

Sur le second appareil, créez un fichier .agent.env à la racine du projet. Renseignez l'adresse HTTPS de votre serveur, son identifiant et son jeton.

Ne placez jamais les jetons dans un dépôt public. Pour un accès distant, HTTPS et contrôle d'accès réseau sont obligatoires.

Mode d'emploi & sécurité

Installation, portée réelle de la protection et recommandations pour la production.

01

Initialiser le serveur

Sur PC ou serveur, dans le dossier du projet :

python -m pip install -r requirements.txt
python -m aegis.cli init
uvicorn aegis.main:app --host 127.0.0.1 --port 8765

Ouvrez http://127.0.0.1:8765 et connectez-vous.

02

Activer la collecte

Le fichier local .agent.env est créé à l'initialisation. Dans un second terminal :

python -m agent.collector --once
python -m agent.collector --interval 60

Les relevés réels apparaissent après la première collecte réussie.

03

Connecter les outils open source

Installez séparément les logiciels officiels. Configurez les chemins de logs : AEGIS_SURICATA_EVE_PATH, AEGIS_FALCO_JSON_PATH, AEGIS_WAZUH_ALERTS_JSON_PATH, ou le binaire AEGIS_OSQUERY_BIN.

Les outils tiers ne sont pas inclus et ne sont pas installés automatiquement.

04

iPhone, iPad, Android

Accédez au tableau de bord par HTTPS, puis ajoutez-le à l'écran d'accueil. Cette PWA supervise les appareils déjà enrôlés mais ne peut pas inspecter ni bloquer l'ensemble des processus d'iOS ou Android.

05

Sécurité des accès distants

Conservez le serveur en écoute locale et utilisez un proxy HTTPS sécurisé, un VPN d'administration et une authentification forte du réseau. N'exposez jamais le service brut sur Internet.

06

Comprendre les prédictions

Le score de risque est un indicateur opérationnel (0–100), pas une probabilité d'intrusion. La projection n'est calculée qu'après cinq mesures ; le modèle local d'anomalies utilise trente mesures ou plus et peut être trompé.
